- Installable signed Android APK: `releases/AperoRoyale-v1.0.0.apk`
- Package: `com.aperoroyale`
- Minimum Android version: 8.0 (API 26)

- Signing certificate SHA-256: `3128c11a3bdfba86472d2ca304cafe4105b8d1e13f20d56986ed10c20f94e120`

Verified on Android 8.0 and 16 emulators. The ten mini-games, turn rotation, scoring, SQLite persistence and French/English handoff were exercised on Android 16. A host and guest emulator completed a shared Wi-Fi turn. Spotify playback was implemented using OAuth PKCE and Web API but could not be exercised without a configured Spotify developer app, authorized user and active Premium playback device. The offline Blind Test and music work without Spotify.
